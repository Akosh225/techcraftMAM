# TechCraft — сайт-портфолио IT-компании

Многостраничный адаптивный сайт вымышленной студии разработки ПО TechCraft (демонстрационный проект).

## Краткое описание
Сайт показывает услуги IT-компании, портфолио проектов, процесс работы и форму обратной связи.
Дизайн: чёрный фон, «жидкий металл» на кнопках, анимированный фон из частиц, serif-акценты в заголовках.

## Структура проекта
```
techcraft/
├── index.html        — главная (первый экран, избранные кейсы, услуги, процесс)
├── portfolio.html    — портфолио: фильтр, поиск, модальное окно
├── services.html     — услуги, процесс, стек, FAQ-аккордеон
├── contacts.html     — форма заявки с валидацией и контакты
├── css/style.css     — все стили и media queries
├── js/script.js      — вся интерактивность
├── images/           — SVG-иллюстрации кейсов (case-*.svg)
└── README.md
```

## Технологии
HTML5 (семантика: header, nav, main, section, article, aside, footer, dialog), CSS3 (Flexbox, Grid, переменные,
Media Queries), JavaScript (ES5, без библиотек и фреймворков). Шрифты: Inter и Cormorant Garamond (Google Fonts).

## Реализованные функции
- Адаптивность: Desktop ≥1200px, Tablet 768–1199px, Mobile ≤767px (меню-бургер, перестройка сеток, без горизонтального скролла)
- Бургер-меню на экран целиком (Esc, клик по пункту и ресайз закрывают его)
- Фильтр проектов по категориям + текстовый поиск
- Модальное окно (`<dialog>`) с деталями проекта
- Аккордеон FAQ (с `aria-expanded`)
- Форма заявки: input, select, textarea, checkbox, button; JS-валидация (обязательные поля, email, телефон,
  минимальная длина, сообщения об ошибках и об успешной отправке); данные на сервер не отправляются
- Анимированный фон (canvas 2D), анимации появления, `prefers-reduced-motion`
- Доступность: alt у изображений, подписи полей (`label`), `aria-live`, ссылка «Перейти к содержимому», фокус с клавиатуры

## Как запустить
Откройте `index.html` в браузере или запустите через расширение **Live Server** в VS Code.
Для шрифтов нужен интернет (без него подставятся системные).

## Тестирование
Проверить в Chrome, Edge и Firefox; размеры — через DevTools (F12 → Ctrl+Shift+M): 1440px, 1024px, 768px, 390px.
